Notation of Terraristic Livestock

12.05.2025 terraristics notation

Summary

A consistent notation system for terraristic livestock is essential for managing, documenting, and sharing information on captive animals — especially in private collections, breeding projects, and scientific exchanges.

Key Concepts

  • Scientific Name First: Always use Genus species as primary identifier (e.g. Scolopendra dehaani).
  • Locality Data: Include origin/locality information if available (e.g. “Thailand, Chiang Mai”).
  • Quantity and Sex: Denote with shorthand (e.g. 1.2.0 for 1 male, 2 females, 0 unsexed).
  • Acquisition Info: Include date, source (e.g. breeder, expo, WC), and conditions.
  • Individual Codes: Use short unique IDs per specimen (e.g. SD-2023-02-f1).
  • Status: Optional status like “active”, “deceased”, “paired”, “for sale”, etc.
